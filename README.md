> A modern **Employee Management System** frontend built with **React, React Native, TailwindCSS, and JavaScript**.  
> Designed for seamless web and mobile experiences with a clean and responsive UI.  

---

## ✨ Features

- 📋 **Employee Dashboard** – Add, update, view and manage employees  
- 🏢 **Department & Role Management** – Assign departments and roles to employees  
- 📊 **Attendance Tracking** – Visual representation with charts  
- 🔐 **Authentication-Ready** – Easily integratable with backend auth APIs  
- 🎨 **Responsive Design** – Powered by TailwindCSS for web & mobile compatibility  
- 📱 **Cross-Platform** – React Native support for mobile applications
- ⛳ **Leave-Management** - Manages employee leave applied by an employee
- ❌ **Support Management** - Employee can raise a query and can be resolved by IT team
- 📂 **Projuct & Product** - Manages and assign project to an employee
- 📫 **Holiday & Calenders** - Manages all leaves and monthly calanders

---

## 🛠️ Tech Stack

- **Frontend Framework**: React.js  
- **Mobile**: React Native  
- **Styling**: TailwindCSS  
- **Language**: JavaScript (ES6+)  
- **State Management**: React Hooks & Context API  
- **Charts**: Recharts  

---

## 🚀 Getting Started

### 🔧 Prerequisites
Make sure you have the following installed:
- [Node.js](https://nodejs.org/) (v16+ recommended)  
- npm or yarn package manager
- Install tailwind from official website 

### 🎦Project Structure
```
employee-management-system-frontend/
│── src/
│   ├── components/       # Reusable UI components
│   ├── pages/            # Page-level components
│   ├── assets/           # Images, icons, etc.
│   ├── hooks/            # Custom React hooks
│   ├── context/          # Context API for global state
│   ├── utils/            # Helper functions
│   └── App.js            # Main entry point
│
├── public/               # Static files
├── package.json          # Project config & dependencies
└── tailwind.config.js    # TailwindCSS config
```
